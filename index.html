Features

Non-blocking API calls via task.spawn with conversation history

🎭

Persona System

🔐

Secret Auth

Roblox Secrets integration with fallback query-param auth

💬

Chat Commands

ProximityPrompt

Click-to-interact NPC dialogue with visual feedback

🛡️

Rate Limiting

Per-player request throttling and graceful error handling

Installation

1

Import the Module

Copy src/PollinationsNPC.lua to ServerScriptService → Modules → PollinationsNPC

2

Set Up API Key

Add POLLINATIONS_API_KEY to Roblox Secrets in Creator Dashboard

3

Add Example NPC

Copy src/ExampleNPCScript.lua to ServerScriptService

4

Enable HTTP

Enable HTTP Requests in Game Settings → Security

Usage Examples

local PollinationsNPC = require(game.ServerScriptService.Modules.PollinationsNPC)

local npc = PollinationsNPC.new({
    model = "openai/gpt-5.4-nano",
    systemPrompt = "You are a pirate captain.",
    apiKey = game:GetService("ServerStorage"):GetSecret("POLLINATIONS_API_KEY") or "",
    temperature = 0.8,
})

print(npc:GetGreeting())
local reply = npc:AskPlayer("Where is the treasure?")
print(reply)
local npc = PollinationsNPC.new({
    model = "openai/gpt-5.4-nano",
    systemPrompt = "You are a wise wizard.",
    apiKey = game:GetService("ServerStorage"):GetSecret("POLLINATIONS_API_KEY"),
    maxConversationTurns = 10,
    rateLimitSeconds = 3,
})

npc:SetupProximityPrompt(workspace.NPCModel)
npc:SetupChatCommand("Wizard")
npc:SetupPlayerEvents()

npc:OnPlayerQuestion(function(player, question, reply)
    print(player.Name .. " asked: " .. question)
    print("NPC replied: " .. reply)
end)
-- Players type in chat:
-- @Wizard What is the meaning of life?
-- @Wizard Tell me a story
-- @Wizard Where should I go next?

-- The NPC responds with AI-generated dialogue
-- that appears in a speech bubble above their head

API Reference

Method Description
PollinationsNPC.new(config) Create a new NPC instance
npc:GenerateText(prompt, model?) Generate text from prompt (sync)
npc:GenerateTextAsync(player, question, callback) Generate text with history (async)
npc:AskPlayer(question) Ask NPC a question (sync)
npc:AskPlayerAsync(player, question, callback) Ask NPC a question (async)
npc:SetupProximityPrompt(model, text?) Setup ProximityPrompt interaction
npc:SetupBillboardGui(model, text?) Setup speech bubble display
npc:SetupChatCommand(name?) Setup @NPCName chat handler
npc:SetupPlayerEvents() Setup player join/leave events
npc:OnPlayerQuestion(callback) Register question callback
npc:Destroy() Cleanup all connections

FAQ

Do I need a Pollinations API key?

No, but it's recommended. Without a key, the module uses fallback auth with rate limits. With a key, you get higher limits and more models.

How do I change the NPC's personality?

Use npc:SetPersona("Your new system prompt") or set systemPrompt in the config.

How do I limit API costs?

Set rateLimitSeconds higher, reduce maxTokens, or use a cheaper model.

Can I use multiple NPCs?

Yes! Create multiple instances with different configs for different personas.
